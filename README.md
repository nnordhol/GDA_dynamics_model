Gene-duplication-amplification model accompanying the paper "Gene amplification mediated heteroresistance delays fixation of stable resistance but rescues small populations under antibiotic stress" by Johannes Kupke1, Yuwen Fang1, Fereshteh Ghazisaeedi1, Dennis Hanke1, Frank Schreiber2, Karsten Tedin1, Niclas Nordholt2* & Marcus Fulde1,3, 4*.

The model is implemented in Python. GDA_ODEvolution_final.py contains the model code, Plots_paper_final.ipynb contains code to generate plots from the paper and other usage examples.
